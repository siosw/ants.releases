# ants CLI releases

Prebuilt ants CLI binaries for macOS and Linux (x86-64 and ARM64).

## Install

```sh
curl --proto '=https' --tlsv1.2 -LsSf https://github.com/siosw/ants.releases/releases/latest/download/ants-installer.sh | sh
```

After installation, run `ants --help` or `ants init`.

This repository hosts release artifacts only. The application source is private.
